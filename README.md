# FSD Lab 10 - MongoDB CRUD Operations

## Aim

To perform CRUD operations on a MongoDB collection using the mongosh shell and MongoDB Atlas.

## Database

- Database: library
- Collection: books

## Operations Performed

1. Created/used the library database.
2. Inserted three book documents.
3. Retrieved all books.
4. Retrieved books by a specific author.
5. Updated the year of a book.
6. Deleted a book by title.
7. Verified the final collection.

## Technologies Used

- MongoDB Atlas
- MongoDB Shell (mongosh)
- PowerShell
